# USB Hub Project
This the first altium project that I put on github. 
I am using a VL817 Chip to design a 4 port USB hub. This chip can handle USB 3.2 Gen 2. I am putting 5 USB 3.1 ports, 4  Upstream and 1 Downstream.
10/06/26 For sake of simplicity I am gonna just USB type A ports, but in future I will change at least one port to USB C. Input power is supplied using a Power Jack, that is not my ideal power supply. I am gonna change this one to a USB C too.
